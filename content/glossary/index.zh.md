本术语表简要定义了 Ardour 8 FLOSS 教程中使用的许多术语。

**聚合设备 (Aggregate Device)** (macOS)
: 聚合设备是由两块或多块物理声卡组合而成的一块虚拟声卡。2007 年或之后生产的 PowerBook 和 MacBook 需要进行此项设置，以便 _JACK_ 同时拥有输入和输出通道。这需要在 _音频 MIDI 设置_ (Audio MIDI Setup) 应用程序中进行配置。

**AIFF**
: 由 Apple 开发的一种声音文件格式，通常用于无损无压缩音频。AIFF 文件兼容 Windows、Macintosh 和 Linux 操作系统。

**ALSA** (Linux)
: 高级 Linux 声音架构 (Advanced Linux Sound Architecture)。ALSA 为 Linux 操作系统提供音频和 MIDI 功能。

**振幅 (Amplitude)** (混音)
: 音频信号的强度。振幅的刻度是*对数* 的，因为它表示一种声音与另一种声音之间功率的物理比值。数字音频系统中的电平通常表示为低于 0 dB 削波点的分贝数。另见 _响度_ (loudness)。

**待命 (Arm)** (音轨待命录音/Ardour 待命录音)
: 使 Ardour 准备开始录音的动作。在 Ardour 中录音之前，必须先让一个或多个音轨进入待命状态，然后 Ardour 本身也需要进入待命状态。

**伪影 (Artifacts)** (声音)
: 因某些信号处理操作作为副产品而产生的可感知失真或音质下降。伪影通常被认为是有意的声音处理过程中产生的非预期或不良结果。

**衰减 (Attenuation)**
: 降低音频信号的**电平**，通常使用 _对数_ 刻度来衡量。另见 _增益_ (gain)。

**音频 MIDI 设置 (Audio MIDI Setup)** (macOS)
: 音频 MIDI 设置实用程序是 macOS 操作系统自带的一个程序，用于调整计算机的音频输入和输出配置设置以及管理 MIDI 设备。

**音频单元插件 (Audio Unit Plugins)**
: 音频单元 (AU) 是 macOS 计算机中的一种插件架构。它可以被视为 Apple 对 Steinberg 流行的 VST 插件格式的对应物。macOS 自带了一系列 AU 插件，如 EQ 滤波器、动态处理器、延迟、混响、时间拉伸等。

**试听 (Audition)**
: 试听器是一个隐藏的混音通道条，试听的片段通过它进行回放。试听片段将仅播放该片段，而不经过发送或插件处理。

**自动化 (Automation)**
: 自动化是对各种参数（如增益、声像或插件设置）的自动调整。更改可以执行一次，然后在每次回放混音时重复。Ardour 中的自动化由链接到每个音轨或总线的自动化线控制。

**辅助控制 (Auxiliary Controls)**
: 位于编辑器窗口控件右上角的按钮：切入/切出 (Punch In/Out)、自动播放 (Auto Play)、自动返回 (Auto Return)、自动输入 (Auto Input)、节拍器 (Click)、独奏 (Solo) 和试听 (Audition)。

**振幅 (Amplitude)**
: 信号的电平或幅度。振幅较高的音频信号通常听起来更响。

**频段 (Bands)** (均衡)
: 在 _均衡处理_ (Equalization) 过程中被提升或衰减的特定频率区域。

**小节 (Bars)** (音乐)
: 小节是一个节拍单位。在西方记谱法中，它是五线谱上画出的两条垂直线之间的空间。小节的具体持续时间取决于其 _拍号_ (time signature) 和当前音乐的 _速度_ (tempo)。

**低频/低音 (Bass)** (频率)
: 指声音 _频谱_ (spectrum) 中较低频率的通用术语。

**拍 (Beat)**
: 构成一段音乐基础的基本脉冲。

**每分钟节拍数 (Beats per Minute)**
: 每分钟节拍数 (BPM) 是音乐中速度的衡量标准。60 拍/分钟的速率意味着每秒发生一拍；120 bpm 等于每秒两拍，以此类推。BPM 指示通常作为节拍器标记出现在传统乐谱的开头（例如，“四分音符等于 60”，意思是每秒一个四分音符）。

**比特 (Bit)**
: 一个比特（**bi**nary dig**it**，二进制数字）是一个单值，其值为 0 或 1。

**位深 (Bit Depth)**
: 指用于写入 _采样_ (sample) 的比特数。在 CD 标准中，每个音频采样由 16 位数字表示。这提供了 2\^16（2 的 16 次方 = 65,536）个可能的采样值。更高的位深意味着更大的可能 _动态范围_ (dynamic range)。录音室录音通常首先以 24（或者 32）的位深进行录制，以便在转换为 CD 之前保留尽可能多的细节。DVD 以 24 位制作，而 1980 年代的电子游戏因其独特粗糙的“8位（8-bit）”而闻名。位深也称为**字长** (word length)。

**缓冲区大小 (Buffer Size)** (JACK)
: 缓冲区是专门分配给临时信号数据的内存区域。较小的缓冲区大小可以实现较低的延迟，因此在使用需要实时交互的音频应用程序时是必需的。缺点是缓冲区越小，系统的 CPU 消耗就越高。当没有这种需求时，可以使用较大的缓冲区（如 512 或 1024）。

**内置输入和输出 (Built-in Input and Output)**
: 如果你没有外置声卡，这些是让声音进出计算机的默认接口。在笔记本电脑中，它们是常见的输入（麦克风）和输出（耳机）接口。

**总线 (Bus)**
: 总线类似于音轨，不同之处在于它不包含自己的片段。你不能直接录制到总线中，也不能将片段拖入其中。_混音器_ (Mixer) 的通道条垂直表示总线的信号流，而主编辑区则水平显示每条总线的基于时间的信息（例如自动化线）。

**BWF**
: 广播波形格式 (Broadcast Wave Format, BWF) 是流行的 Microsoft WAVE 音频格式的扩展，是用于电影和电视制作的大多数基于文件的非线性数字录音机的录音格式。这种文件格式允许包含元数据，以促进不同计算机平台和应用程序之间声音数据的无缝交换。

**CAF**
: CAF (Core Audio Format) 是 Apple 开发的一种用于存储音频的文件格式。它兼容 macOS 10.4 及更高版本。核心音频格式旨在克服旧数字音频格式（包括 AIFF 和 WAV）的局限性。就像 QuickTime .mov 文件格式一样，.caf 文件格式可以包含许多不同的音频格式、元数据轨道以及更多数据。

**中心频率 (Center Frequency)**
: 在某些 EQ 插件中，用户可以为每个频段选择中心频率。频段的中心频率，就是均衡器针对该频段衰减或提升幅度最大（最显著）的频率。中心频率周围的频率受到的影响较小。

**单击 (Click)** (鼠标)
: 在本手册中，特指单击鼠标左键。凡是需要右键的地方，该动作被称为“右键单击” (right-click)。

**削波 (Clipping)**
: 当信号电平过高而无法重现时，就会发生削波。任何电平过高的采样都会被简单地截断，从而导致 _失真_ (distortion)、音频细节丢失，以及产生原声中不存在的杂散频率（artefact frequencies）。”

**削波点 (Clipping Point)**
: 数字系统的削波点被称为 0 dB，任何声音的电平都是以它低于削波点多少来衡量的（-10 dB、-24 dB 等）。

**时钟 (Clocks)**
: 位于 _编辑器_ 窗口顶部附近的两个大型数字显示器。它们可以以多种格式显示时间：_时间码_ (Timecode)、_小节:拍子_ (Bars:Beats)、_分:秒_ (Minutes:Seconds) 、 _秒_（Seconds） 和 _样本_ (Samples)。

*（注：Ardour 9.8 新增了“秒”格式，本手册已补全，英文原版目前仍为 4 种）*

**编译 (Compile)**
: FLOSS 应用程序以源代码形式分发，源代码是人类可读的，但不能作为实际应用程序运行。要将此源代码转换为运行中的应用程序，必须先对其进行编译。当你下载 macOS 的磁盘映像或发行版（如 Ubuntu、Debian 或 Fedora）的软件包时，它已经为你编译好了。但是，如果你希望添加发行版未提供的功能（例如支持 _VST 插件_），那么你必须自己从源代码编译该应用程序。

**压缩 (Compression)**(DSP)
: 从本质上讲，压缩使信号中安静的部分变响，而不改变较响部分的电平。这导致了实际动态范围的缩小：压缩后的声音动态较小（即电平范围较小）。

**压缩 (Compression)** (数据)
: 像任何其他数据一样，音频数据可以被压缩，以便占用更少的硬盘空间。与 WAV 或 AIFF 相比，FLAC、ALAC 或 MLP 等压缩技术可以在不改变数据的情况下减小音频文件的大小，这被称为无损压缩。使用 MP3、Ogg Vorbis、AAC或者Opus 等有损压缩可以将音频压缩到更小的尺寸，但这是通过删除可能产生听觉影响的数据来实现的。

**连接管理器 (Connections Manager)**(JACK)
: Jack 中的一个窗口，允许管理音频输入和输出之间的所有连接。

**CoreAudio**(macOS)
: CoreAudio 为 macOS 操作系统提供音频功能。

**光标模式 (Cursor Modes)**
: 这是编辑器窗口走带控制命令正下方的六个按钮。鼠标指针在 Ardour 中可以具有的六种不同功能是：选择/移动对象 (Select/Move Objects)、选择/移动范围 (Select/Move Ranges)、选择缩放范围 (Select Zoom Range)、绘制增益自动化 (Draw Gain Automation)、拉伸/收缩片段 (Stretch/Shrink Regions)、监听特定片段 (Listen to Specific Regions)。

**分贝 (Decibels)**
: 分贝是一种对数刻度，用于测量许多量，包括信号的_增益_ (gain)、_电平_ (level) 或 _响度_ (loudness)。分贝通常缩写为 dB，在数字音频中通常表示信号低于 0 dBFS（系统的 _削波_ 
点）多少。

**延迟 (Delay)** (效果)
: 一个事件与另一个事件之间的时间量。作为一种音频效果，延迟接收输入的原始声音信号并将其延迟一定的时间长度。当与原始声音混合时，会听到“回声”。通过使用 _反馈_ (feedback) 将延迟信号返回到延迟中（通常在降低其 _增益_ 之后），会产生带有 _衰减_ (decay) 的多次回声。

**破坏性编辑/录音 (Destructive Editing/Recording)**
: 破坏性操作是指在编辑或录音过程中永久修改或擦除原始数据（声音文件）的操作。

**失真 (Distortion)**
: 当音频信号以某种方式发生变化，产生原声中不存在的 _频率_ 时，就会发生失真。失真可以是有意的，也可以是不受欢迎的，可以通过将信号推至 _削波点_ 来产生，也可以通过使用数学变换来改变信号的形状（或“波形”）来产生（通常称为“波形整形”）。

**磁盘映像 (Disk Image) (.dmg)**
: 磁盘映像是一个包含代表数据存储介质或设备的完整内容和结构的单个文件。在 Mac 上双击 .dmg 文件，一个虚拟设备将挂载到你的桌面上（例如，看起来就像你插入了一个 USB 设备或 DVD）。OS X 中的许多软件安装程序都以 .dmg 文件的形式提供。

**驱动程序 (Driver)**(JACK)
: 为控制硬件而编写的软件。CoreAudio 是 Mac 的声音驱动程序。ALSA 是最常见的 Linux 驱动程序。

**DSP**
: 数字信号处理 (Digital Signal Processing)。

**动态范围 (Dynamic Range)**
: 用于指代可能被录制的最响亮和最安静声音之间的差异，以及在这些极端之间能听到的细节量。太安静而无法录制的声音被称为低于录音系统（麦克风、录音机、声卡、音频软件等）的**本底噪声** (noise floor)。太响亮的声音将会**失真**或被**削波**。

**编辑模式 (Edit Modes)**
: 三种可用的编辑模式（**滑行编辑**、**波纹编辑**和**锁定编辑**）控制**主编辑区**中的编辑操作行为。

**编辑点 (Edit Point)**
: 主画布中执行粘贴等操作的点。这可以是鼠标、播放头或标记。

**编辑器窗口 (Editor Window)**
: Ardour 提供两种查看会话的方式：编辑器 (Editor) 和混音器 (Mixer)。编辑器代表会话基于时间的方面：它将音轨和总线显示为水平的时间轴显示，音轨内的素材（音频、MIDI、视频、自动化数据等）沿水平（时间）轴排列。

**EQ**
: 参见均衡 (Equalization)。

**均衡 (Equalization)**
: 均衡 (EQ) 是调整录音或信号中不同频率相对电平的过程。换句话说，它是根据选定的预期的听觉效果提升或衰减声音各个频段的过程。

**滤波器 (Filter)**
: 一种抑制某些频率的信号处理类型。

**浮点数 (Floating Point Numbers)**
: 它只是一个带有小数点的数字。“浮点”指的是计算机用于表示更大范围的整数和非整数值的一种技术。

**FLAC**
: 一种开源的无损音频格式，通常兼容 Linux、Windows 和 Macintosh。与 AIFF 和 WAV 不同，FLAC 是一种压缩格式，可以减小文件大小。

**FLOSS**
: FLOSS 代表自由/开源软件 (Free Libre Open Source Software)。FLOSS Manuals 是一个关于自由和开源软件的文档集合，以及用于创建它们的工具和使用这些工具的社区。他们包括作者、编辑、艺术家、软件开发人员、活动家等等。

**格式 (Format)** (音频文件)
: 声音保存为声音文件的类型。最常见的包括 AIFF、WAV、FLAC、mp3 和 Ogg Vorbis。

**fps**
: 每秒帧数 (Frames Per Second)。帧率或帧频率是成像设备产生称为帧的唯一连续图像的频率（速率）。该术语同样适用于计算机图形学、摄像机、胶片相机和动作捕捉系统。帧率最常以每秒帧数 (FPS) 表示。

**频率 (Frequency)**
: 指一秒内发生振荡的次数。频率以**赫兹** (Hertz) 为单位测量，并与声音的**音高** (pitch) 相关。频率是一个**线性** (linear) 刻度，而音高是**对数** (logarithmic) 刻度。中央 C 上方的音高 'A' 的频率为 440 Hz。高一个八度的 'A' 频率是该频率的两倍（880 Hz）。

**增益 (Gain)**
: 增加音频信号的**电平**，通常使用**对数**刻度来衡量。另见**衰减** (attenuation)。

**网格 (Grid)**
: 网格是一个点系统，在编辑时片段可以吸附到其上。网格可以是“无网格” (No Grid)、“网格” (Grid) 或“磁性” (Magnetic)。

**网格点 (Grid Points)**
: 当**网格**激活时，片段将吸附到的网格中的点。网格点可以是分钟、秒、视频帧、小节、拍或拍的倍数。

**赫兹 (Hertz)**
: 用于描述一秒内某事发生次数的术语。在数字音频中，它用于描述**采样率** (sampling rate)，在声学中，它用于描述声音的**频率** (frequency)。数千赫兹被描述为 kHz（千赫兹）。

**高架 (High Shelf)**
: 在**均衡器**中，**搁架** (Shelf) 会切除或提升特定频率以上（高架）或以下（低架）的所有内容。

**余量 (Headroom)**
: 片段的最高**峰值** (Peak) 与**削波点** (Clipping Point) 之间的**分贝**范围通常被称为**余量**。常见的录音做法是在信号最大值和削波点之间保留大约 3 到 6 分贝的余量。

**Jack 音频连接套件 (Jack Audio Connection Kit (JACK))**
: JACK 是一个低延迟音频系统，负责管理 Ardour 与计算机声卡之间，以及 Ardour 与计算机上其他支持 JACK 的音频程序之间的连接。在使用 Ardour 之前，必须安装适用于 Linux 的 JACK 或 JackOSX。

**JackOSX** (OS X)
: 在 macOS 上运行的 **JACK** 版本名称。有关详细信息，请参阅 **JACK**。

**JackPilot**
: JackOSX 附带的控制界面。

**Jack 服务器 (Jack Server)**
: Jack 服务器是 Jack 音频连接套件的“引擎”或“后端” (backend)。

**Jack 路由器 (Jack Router)**
: Jack 路由器允许使用 **Jack 服务器**将音频从一个应用程序路由到另一个应用程序。

**JAMin**
: JAMin 是 Jack 音频连接套件的音频母带处理界面。JAMin 是一个开源应用程序，旨在对立体声输入流进行专业音频母带处理。它使用 **LADSPA** 进行数字信号处理 (DSP)。

**LADSPA 插件**
: Linux 音频开发者简单插件 API (LADSPA) 是一种标准，允许将软件音频处理器和效果器插入到各种音频合成和录音包中。例如，它允许开发者编写一个混响程序并将其捆绑到一个 LADSPA“插件库”中。然后普通用户可以在任何支持 LADSPA 的音频应用程序中使用这个混响。Linux 上的大多数主流音频应用程序都支持 LADSPA。

**延迟 (Latency)**
: 延迟是指处理来自计算机声音应用程序的所有采样并将其发送到声卡进行播放，或者从声卡收集采样进行录音或处理所需的时间量。延迟越短意味着你能更快地听到结果，给人一种系统响应更快的印象。然而，延迟越短，音频出现**故障** (glitches) 的风险也越大，因为计算机在将声音发送到声卡之前可能没有足够的时间来处理它。延迟越长意味着故障越少，但代价是响应时间变慢。延迟以毫秒为单位测量。

**限制 (Limiting)**
: 防止设备输出的振幅超过预定值的过程。

**线性 (Linear)**
: 以加法方式递进的数字刻度，例如加一 (1, 2, 3, 4...)、加二 (2, 4, 6, 8...) 或加十 (10, 20, 30, 40...)。例如，将音频信号乘以线性或对数刻度将产生截然不同的结果。**频率**的刻度是线性的，而**音高**和**增益**的刻度是对数的。

**Linux 内核 (Linux kernel)**
: GNU/Linux 操作系统的核心。在**实时系统** (Real-time System) 中，该内核通常使用新的参数进行**编译**，以加速系统中音频应用程序的使用。

**锁定编辑 (Lock Edit)**
: 三种可用**编辑模式**之一，锁定编辑类似于**切片编辑**，但无论执行何种编辑操作，片段都将保持在原始位置。

**对数 (Logarithmic)**
: 根据一定比例递进的数字刻度，例如指数级 (2, 4, 8, 16, 256...)。**音高**和**增益**的刻度都是对数的，而**频率**的刻度是线性的。

**无损 (Lossless)**
: 参见**压缩** (数据)。

**有损 (Lossy)**
: 参见**压缩** (数据)。

**响度 (Loudness)**
: 与表达声音物理功率的**振幅**不同，响度是声音的感知强度。即使振幅相同，不同频率的音调也可能被感知为具有不同的响度。

**LV2**
: LV2 是插件和匹配宿主应用程序的开放标准，主要针对音频处理和生成。LV2 是 LADSPA 的简单但可扩展的继承者，旨在解决许多应用程序已不再适用的 LADSPA 局限性。

**主画布 (Main Canvas)**
: 在 Ardour 的编辑器窗口中，主画布是时间轴标尺正下方的空间，音轨和总线在此水平显示。

**主输出 (Master Out)**
: 主输出是一条总线，所有（或大部分）音轨和其他总线将其输出发送到该总线。它为 Ardour 的输出提供了一个方便的单一控制点，并且是全局效果的典型位置。默认情况下启用主输出，主输出总线设置为立体声。

**节拍/拍号 (Meter)**
: 将强拍和弱拍分组为更大的单位，称为小节 (bars) 或 measures。

**混音 (Mixing)**
: 音频混音是将大量录制的声音组合到一个或多个通道（最常见的是双声道立体声）的过程。在此过程中，通常会操纵源信号的电平、频率内容、动态和声像位置，并可能会添加混响等效果。

**MIDI**
: MIDI 是一种行业标准协议 [定义于 1982 年](http://en.wikipedia.org/wiki/Musical_Instrument_Digital_Interface#cite_note-0)，它使电子乐器（如键盘控制器、计算机和其他电子设备）能够相互通信、控制和同步。MIDI 允许计算机、合成器、MIDI 控制器、声卡、采样器和鼓机相互控制，并交换系统数据。MIDI 不传输音频信号，只传输诸如音符编号（音高）、力度（强度）、音符开 (note-on) 和音符关 (note-off) 之类的消息。

**混音通道条 (Mixer Strip)**
: 每个音轨和总线在混音器窗口中由垂直的**混音通道条**表示，其中包含与信号流相关的各种控件。在 Ardour 中有两个地方可以看到混音通道条。混音器窗口是最明显的一个，但你也可以在编辑器左侧查看单个混音通道条（Shift + E 隐藏/查看）。

**混音器窗口 (Mixer Window)**
: 混音器通过将音轨垂直表示为混音通道条来显示会话，带有增益、录音启用、独奏、插件等控件。混音器代表 Ardour 会话中音轨和总线的信号流。混音器窗口提供了一种模仿传统硬件调音台的视图。

**监听 (Monitoring)**
: 监听是将会话的特定混音或子混音路由到单独输出（如耳机）的过程。例如，正在录音的音乐家可能希望在演奏时监听现有素材。Ardour 和 JACK 可以轻松设置监听输出，因为任何输入信号都可以被送回任何输出，并可选择与其他信号混合并添加任何类型的声音处理。

**单声道 (Mono)**
: 单声道声音文件仅包含一个音频通道。Ardour 中的单声道音轨只有一个输入并处理单声道声音文件。

**MP3**
: 一种有损、尺寸压缩的声音文件**格式**。

**图形均衡器/多段均衡器 (Graphic Equalizer/Multi-Band Equalizer)**
: 图形（或多段）均衡器由一排推子组成，用于提升或衰减声音的不同频率。

**非破坏性编辑/录音 (Non-destructive Editing/Recording)**
: 这是一种在编辑过程中不修改原始内容的编辑形式。在后台，原始声音文件保持完整，而你的编辑实际上是一系列指令，Ardour 将在回放时使用这些指令从原始源重建信号。例如，在片段上创建淡入和淡出就是一种非破坏性编辑。

**标准化/归一化 (Normalize)**
: 标准化音频信号意味着调整其**增益**，使其在**削波**之前达到声卡允许的最大峰值。

**普通模式 (Normal Mode)**
: 参见**音轨模式** (Track Mode)。

**音符时值 (Note value)**
: 音符或休止符相对于标准单位的比例持续时间。例如，“四分音符” (quarter note) 之所以被称为四分音符，是因为它的相对持续时间是全音符 (whole note) 的四分之一。

**八度 (Octave)** (音乐)
: 两个音符之间相距 12 个半音的距离。在**赫兹**中，一个八度的比率是 2:1。例如，中央 C 上方的音符 'A' 的频率为 440 Hz。高一个八度的音符 'A' 是 880 Hz，低一个八度是 220 Hz。

**Ogg Vorbis**
: 一种开源的有损、尺寸压缩的声音文件格式。

**声像调整 (Panning)**
: 声像是声音在**立体声声场**中的位置。

**参量均衡器 (Parametric Equalizer)**
: 参量均衡器是用于**混音**的最通用的**EQ**类型，因为它可以对滤波的所有参数进行广泛的控制。

**峰值 (Peaks)**
: 峰值是**片段**最大**电平**的图形表示。

**峰值表 (Peak Meters)**
: 峰值表是片段最高电平的持续显示，位于混音器窗口中的推子旁边，也位于每个音轨的音轨混音器中。

**音高 (Pitch)**
: 音高 [代表](http://en.wikipedia.org/wiki/Pitch_(music)#cite_note-0) 声音被感知的基础频率。它是与响度和音色并列的声音的三大听觉属性之一。在 MIDI 中，音高由 0 到 127 之间的数字表示，每个数字代表 MIDI 键盘上的一个键。音高与**频率**的关系是**对数**的。这意味着听起来比另一个声音高一个**八度**（+12 个 MIDI 音符）的声音频率是两倍，而低一个八度（-12 个 MIDI 音符）的声音频率是一半。

**播放头 (Playhead)**
: 在 Ardour 中，播放头是随着时间（即从左到右）移动以指示当前播放位置的红色线条。

**插件 (Plugin)**
: 在计算机领域，插件由一个与宿主应用程序（在本例中为 Ardour）交互以“按需”提供特定功能（通常是非常具体的功能）的计算机程序组成。混响、滤波器和均衡器是可以在 Ardour 中与音轨或总线关联使用的插件的示例。

**Portaudio**
: 适用于 Linux 和 macOS 的一套免费开源**音频驱动程序**。

**推子后 (Post-Fader)** (插件或发送)
: 在混音通道条中，推子后区域是增益滑块下方的黑色空间，可以在其中添加插件或发送。这些插件和发送的输入将是经过任何手动或自动增益更改*之后*的信号（因此称为“推子后”）。

**推子前 (Pre-Fader)** (插件或发送)
: 在混音通道条中，推子前区域是增益滑块上方的黑色空间，可以在其中添加插件或发送。这些插件和发送的输入将是受滑块控制的任何手动或自动增益更改影响*之前*的输入信号（因此称为“推子前”）。

**量化 (Quantization)**
: 在信号处理中，量化可以指位深（请参阅**位深**定义）。在 MIDI 中，量化是指将音符对齐到精确的时间网格的过程。这导致音符被设置在节拍或节拍的精确分数上。MIDI 音序器通常包含某种类型的量化功能。

**范围 (Range)**
: 时间的一段。范围是使用选择/移动范围工具创建的，可以包含一个或多个音轨。循环和切入范围是使用循环/切入范围电平表创建和操作的特殊类型的范围。

**实时系统 (Real-time System)**(Linux)
: 在**实时系统**中，**Linux 内核**通常会使用新参数重新编译（重建），并优化系统中的其他设置，以加速系统中音频应用程序的使用。

**片段 (Regions)**
: 片段是 Ardour 中编辑和作曲的基本元素。每个片段代表一个音频文件的全部或部分。从音轨中移除片段并不会从磁盘中移除音频文件。

**片段列表 (Region List)**
: 片段列表位于编辑器窗口的右侧，它显示与会话关联的所有片段。

**混响 (Reverberation)**
: 混响是原始声源移除后，声音在特定空间中的[持续存在](http://en.wikipedia.org/wiki/Reverberation#cite_note-0)。当在封闭空间中产生声音时，会产生大量的回声，然后随着声音被墙壁和空气吸收而缓慢衰减，就会产生混响。在 Ardour 中，可以通过使用插件将数字混响添加到声音中。

**右键单击 (Right Click)** (鼠标)
: 单击鼠标右键。

**路由 (Routing)**
: 路由是将音频信号从某处发送到另一处。信号不仅可以从外部世界路由到 Ardour 中，反之亦然，而且也可以在 Ardour 内部路由（例如，从音轨到总线）。

**标尺 (Rulers)**
: 标尺是显示时间线的细水平条，有助于确切了解片段或声音何时开始或停止。标尺上还会显示节拍和速度标记、位置标记、范围标记以及循环/切入范围。

**采样 (Sample)** (数据)
: 在数字音频中，采样是录制声音的最小可能段。例如，在 CD 音频中，每秒录制的声音需要 44,100 个采样，因此我们可以说**采样率**是 44,100 **赫兹**。采样还具有**位深**，它决定了录制和回放可能达到的**动态范围**。常见的位深有 16 位（用于 CD 音频）、24 位（用于录音室录音和 DVD）或 32 位（用于计算机内部的声音）。

**采样 (Sample)** (音乐)
: 在电子音乐中，采样一词可以指从现有音乐作品中提取出来并在新作品中重复使用的任何声音部分。

**采样器 (Sampler)**
: 一种电子乐器或软件，每当发送**音符**消息时，它就会播放录制的声音（或**采样**）。音符的**音高**决定了采样播放的快慢，从而模拟其他乐器的音高变化。采样可以循环播放（一遍又一遍地播放）和一次性播放（仅播放一次）。

**采样率 (Sampling Rate)**
: 计算机录制和回放声音的速率，以**赫兹**衡量，代表每秒的**采样**数。CD 音频以 44,100 Hz（或 44.1 kHz）录制和播放，而 DVD 音频以 96,000 Hz（96 kHz）运行，廉价的消费电子产品，如录音笔、视频游戏、手机、玩具和一些 MP3 播放器，通常使用 22,050 Hz（22.05 kHz）或更低的速率。采样率决定了可以录制或播放的最高**频率**，这由奈奎斯特数（采样率的一半）表示。以不同于录制时的采样率播放声音，会导致听到的声音“速度错误”。

**发送 (Send)**
: 音轨或总线的可选辅助输出。

**会话 (Session)**
: 会话是构成 Ardour 中一个项目的所有信息。每个会话都保存在自己的文件夹中，包含所有音频、片段和参数数据，以及一个扩展名为 .ardour 的主文件。

**搁架 (Shelf)**
: 在**均衡器**中，**搁架**会切除或提升特定频率以上（高架）或以下（低架）的所有内容。

**切片编辑 (Slice Edit)**
: 三种可用**编辑模式**之一，切片编辑不允许拖动片段，但仍允许你执行切片操作（如剪切、粘贴和拆分）。受影响的任何编辑操作后，片段之间的空间将保持不变。例如，如果你删除了片段的后半部分，同一音轨上的任何后续片段都将自动在时间网格中向后移动。

**滑动编辑 (Slide Edit)**
: 三种可用**编辑模式**中的另一种，滑动编辑是默认模式。它允许你水平拖动片段（在同一音轨内）和垂直拖动（在音轨之间）。

**SMPTE 时间码 (SMPTE timecode)**
: 一套协同标准，通过电影与电视工程师协会定义的时间码来标记视频或电影的单个帧。时间码被添加到电影、视频或音频素材中，也已被改编用于同步音乐。它们为编辑、同步和识别提供了时间参考。

**吸附模式 (Snap Mode)**
: **吸附模式**菜单位于**时钟**正下方。它们控制时间网格的**量化**程度，即音频**片段**吸附到你选择的网格类型的程度。

**快照 (Snapshots)**
: 在 Ardour 中保存快照类似于将会话保存到新文件以避免覆盖原始会话文件。快照包含你当前的工作状态，同时共享会话的所有音频和数据文件。如果你试图在 Ardour 中找到“另存为”功能，保存快照可能就是你要找的。

**独奏 (Solo)**
: 在音轨控件和混音通道条中找到的切换开关。打开时，只有独奏的音轨才会发送输出。可以同时将多个音轨标记为独奏。通用的独奏按钮（编辑器窗口控件的顶行）可用于一次性取消所有独奏音轨的独奏状态。

**频谱 (Spectrum)**
: 信号根据其频率成分的表示。

**立体声 (Stereo)**
: 立体声声音文件包含两个音频通道（通常称为左声道和右声道）。Ardour 中的立体声音轨有两个输入和输出，以便录制和播放立体声文件。

**立体声声场 (Stereo Field)**
: 立体声声场是基于 2 通道（左和右）声音再现系统的声音空间位置感知。

**遍次 (Take)**(录音)
: 一次连续录制的一段声音序列。

**磁带模式 (Tape Mode)**
: 参见**音轨模式** (Track Mode)。

**速度 (Tempo)**(音乐)
: 节拍发生的速率。精确的速度指示以 **bpm**（每分钟节拍数）为单位测量，尽管乐谱中也常见主观指示（快板、柔板、非常快等）。

**终端 (Terminal)**
: “终端”是一种基于文本的界面，允许通过在其中输入命令来操作计算机。今天的大多数计算机用户完全依赖图形界面来控制他们的系统。不过，macOS 和 Linux 都包含终端，这可能使某些用户更容易完成某些任务。

**时间码 (Timecode)**
: 时间码是由定时系统以固定间隔生成的一系列数字代码。SMPTE 系列时间码几乎普遍用于电影、视频和音频制作中。

**拍号 (Time Signature)** (音乐)
: 放置在音乐作品开头（在谱号和调号之后）或在其进行过程中，指示音乐节拍的符号。

**音轨 (Track)**
: 音轨是你可以将**片段**从**片段列表**拖放到其中的地方，也是你可以录制来自外部声源的声音的地方。混音通道条垂直表示音轨的信号流，而主画布则水平显示每个音轨的基于时间的信息。

**音轨模式 (Track Mode)**
: **音轨模式**让你在**普通模式**和**磁带模式**之间进行选择。普通模式为每次录音**遍次** (Take) 创建一个新片段，而**磁带模式**进行破坏性录音——换句话说，每次新的遍次都会消除音轨先前的遍次。

**播送 (Transport)**
: 位于编辑器窗口左上角的按钮，包含快退 (Rewind)、播放 (Play)、停止 (Stop) 等控件。

**高频/高音 (Treble)**(频率)
: 指声音**频谱**中高频的通用术语。

**VST (虚拟工作室技术)**
: [Steinberg](http://en.wikipedia.org/wiki/Steinberg) 的 VST 是一种接口，用于将软件音频合成器和效果插件与音频编辑器和数字工作站（如 Ardour）集成。VST 及类似技术使用数字信号处理，用软件来模拟传统录音棚硬件。存在数千种插件，既有商业的也有免费的。VST 由 Steinberg 创建。

**WAV**
: 由 Microsoft 和 IBM 开发的一种声音文件格式，通常用于无损无压缩音频。WAV 文件兼容 Windows、Macintosh 和 Linux 操作系统。

**波形 (Waveform)**
: 声音的时域视觉表示。波形绘制在主画布中代表片段的彩色矩形内。

**字长 (Word length)**
: 参见**位深** (Bit Depth)。
