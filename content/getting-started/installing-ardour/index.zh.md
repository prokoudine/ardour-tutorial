让我们来学习如何在你的操作系统上安装 Ardour。

## Windows

下载安装程序并照常运行即可。在 Windows 11 上，你可能会看到 Microsoft Defender 发出的警告，提示该安装程序是不常见的文件。[这篇指南](https://ardour.org/windows_defender.html) 解释了如何处理该问题。

## macOS

下载 `.dmg` 文件并双击它。窗口打开后，将 Ardour 图标拖放到 Applications（应用程序）图标上即可完成安装。

## Linux

1. 下载 `.run` 文件
2. 进入该文件所在的文件夹：

```bash
$ cd /folder/where/you/saved/the/file
```

3. 在终端运行安装程序：
```
/bin/sh ./<DOWNLOADED_FILENAME>.run
```

4. 按照指示操作

**继续**

现在让我们启动 Ardour
