_导出_ 是将片段、轨道或整个会话保存为计算机上的文件的过程，你可以收听该文件、将其刻录为 CD-R，或将其转换为 MP3 在网站上分享。

## 导出整个会话

完成作曲后，最常见的导出操作就是将整个会话导出为一个音频文件。

### 整个会话的鸟瞰图

此时，在导出之前，最好缩小视图，查看整个会话。

* 从“可见轨道数量”菜单中选择“全部”：

{{< figure alt="track heights" src="en/ardour7-track-height.png" >}}

* 点击 **缩放至会话** 按钮（缩放选项中的第三个按钮）：

![zoom options](en/ardour7-session-zoom-all.png?width=200)

* 现在你应该可以很好地概览整个会话了，就像这样：

{{< figure alt="birds eye view" src="en/ardour7-birds-eye-view.png" >}}

最后再听一遍你的作品，确保你听到的一切都符合预期（有没有忘记取消激活某个 **独奏** 或 **静音** 按钮？还有音量需要调整吗？等等）。

#### 开始和结束标记

最后，确保位置标记时间线上的 _开始_ 和 _结束_ 标记位于正确的位置。

_开始_ 和 _结束_ 标记之间的所有内容都会被导出，因此如果标记位置不正确，你必须先设置好它们。在下图中，很明显 _结束_ 标记在时间线上太靠右了。这将导致作品结尾之后出现大段的静音（即最后一个片段与 _结束_ 标记之间）。

{{< figure src="en/ardour7-end-marker-too-far.png" alt="The end marker is too far" >}}

如果你的 _结束_ 标记远在作品结尾之后，请点击它并向左拖动，直到它非常接近你作曲中最后一个片段的结尾。

## 导出！

要导出一个会话，请使用顶部菜单：
`会话 > 导出 > 导出到音频文件...`。这将打开一个包含许多选项的对话框。

{{< figure alt="Export Session dialog" src="en/ardour7-exporting-settings.png" >}}

**预设**
: 这里*不是*你写文件名的地方。现在不用管这个字段。

**格式**
: 允许你选择文件格式（WAV、MP3、OGG、FLAC 等）。默认是 CD (Red Book)，这会生成一个 16 位、44.1kHz 采样率的 WAV 文件。

**添加另一个格式**
: 如果你想同时导出为多种格式，请点击此选项卡。

**位置**
: 这是文件保存后你找到它的地方。默认情况下，它位于主会话文件夹内的 `export` 文件夹中。你也可以点击 **浏览**，例如选择桌面。

**标签**
: *这里*才是你为文件创建唯一名称的地方。Ardour 会自动将会话名称附加到导出的文件中，所以如果你不在这里写任何内容，名称最终可能会是像 `my-session.wav` 这样笼统的名字。使用这个字段来给你的文件起一个独特的名字。

选择好选项后，点击 **导出**。操作完成后，你可以使用文件浏览器找到该文件。

{{< callout type="info" >}}
导出是通过主控总线处理的，因此最终文件将包含所有路由到它的轨道和总线的声音。这将包括你创建的任何标准化、淡入淡出、声像和自动化，以及对片段进行的单独编辑。如果有任何轨道启用了 **静音** 或 **独奏** 按钮，这也会影响导出文件中听到的轨道。
{{< /callout >}}

## 标准化

有时，渲染出来的音频可能太响或太轻，无法满足 YouTube 或 Spotify 等各种流行流媒体服务的要求。Ardour 提供了一个名为 _响度助手_ 的工具来帮助解决这个问题。

通俗地说，它会分析通过 _主控_ 总线的所有内容，估算信号的响度，然后建议向上或向下校正，以使整体响度对于这个或那个流行流媒体服务来说刚刚好。

虽然你可以直接将响度（增益）校正应用到 _主控_ 总线的输出，并对结果拥有更多手动控制，但最方便的方法是在导出阶段应用标准化。你可以通过两种方式做到这一点：

1. 只需在 _格式_ 下方的下拉列表中选择一个流行的服务。Ardour 有 Apple Music、Deezer、Spotify、YouTube 等的预设。

2. 如果预设中没有列出该服务，请点击 **编辑** 按钮打开高级导出设置对话框，启用 _标准化_，选择 _响度_ 而不是 _峰值_，然后设置所需的 LUFS 值。

{{< figure src="en/ardour7-edit-exporting-format.png" alt="Edit the exporting Format" >}}
