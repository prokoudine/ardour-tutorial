正如你在前面章节中已经了解到的，导出单独的片段并不会导出你可能对该片段所做的所有更改。要导出诸如声像、推子自动化和插件效果等编辑，你必须导出一个范围或整个会话。

## 导出一个范围

要导出一个范围，请按照以下步骤操作：

1. 点击 **范围模式** 按钮（**R** 快捷键）

![Range mode](en/ardour7-range-edit-mode.png?width=250)

2. 建立一个范围选择：

{{< figure src="en/ardour7-exporting-range-1.png" alt="Make a range selection" >}}

3. 右键点击该范围，然后从菜单中选择 _导出范围_：

{{< figure src="en/ardour7-exporting-range-2.png" alt="Export Range in menu" >}}

这将打开你在 [导出会话](../exporting-a-session) 章节中了解过的熟悉的 _导出_ 对话框。选择你的选项（如果有的话），然后点击 **导出**。该范围将被导出并保存为音频文件。

### 究竟什么是范围？

定义一个范围，简单来说就是指定时间上的起点和终点。辅助时钟右侧的 **选择** 显示会展示所选范围的开始和结束时间，以及它的时长。

![Range duration](en/ardour7-range-duration.png?width=600)

通过上述方法创建的范围，一旦你点击范围外部，它就会消失。

_导出范围_ 命令会导出通过 _主控_ 总线播放的所有内容，完全就像它在你的会话中回放一样。如果有任何轨道启用了 **静音** 或 **独奏** 按钮，这也会影响导出文件中听到的轨道。

### 如何创建范围标记并重新选择一个范围

范围标记本质上是由两个位置标记组合在一起，用于标记时间线上某个区域的开始和结束。范围标记看起来像这样：

{{< figure src="en/ardour7-range-markers.png" alt="Range markers" >}}

你可以使用范围标记来“收藏”一个或多个你需要记住或以后再使用的范围。以下是操作方法。

1. 在 _范围_ 模式下，或者在启用了 _智能_ 选项的 _抓取_ 模式下，建立一个范围选择。

2. 通过以下方式之一创建范围标记：

* 右键点击一个范围选择，然后选择 _添加范围标记_。
* 在时间线上，右键点击 _范围标记_ 的横向空白区域，然后选择 _新建范围_。
* 在一个或多个选中的片段上，右键点击片段并选择 _添加单个范围标记_（如果选中了单个片段），或者 _为每个片段添加范围标记_（如果选中了多个片段）。

3. 点击范围选择外部的任意位置以取消选择。

4. 右键点击时间线上两个范围选择标记中的任意一个，然后选择 _选择范围_ 菜单选项。该范围选择将被恢复。

{{< callout type="info" >}}
你可以通过右键点击时间线上的 _范围标记_ 区域并选择 _清除所有范围_，来清除所有现有的范围标记。
{{< /callout >}}
