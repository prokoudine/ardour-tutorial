几乎所有的 MIDI 编辑都在 _内部编辑_ 模式（**E** 快捷键）下进行。这里绝大多数工作涉及调整音符的位置和时值、调整力度以及编辑自动化。Ardour 提供了交互式和数值式两种方式来编辑这些设置。

那么让我们回顾一下可用的工具，然后做一个快速练习。

大多数编辑操作都假定在 MIDI 片段中至少选中了一个音符。我们从选择音符开始。

## 选择音符

在 _内部编辑_ 模式下，有多种方式可以选择音符，这实际上取决于你想做什么。

要选择一个音符，单击它即可。要将另一个音符添加到选择中，按住 **Ctrl** 键，然后单击该音符。要从选择中移除音符，同样按住 **Ctrl** 键，然后单击它。

如果你需要将现有的选择扩展到另一个音符，并包含其间的所有音符，请按住 **Shift** 键，然后单击你想要扩展选择到的那个音符。

要选择多个相邻的音符，你可以进行常规的框选操作。把鼠标指针移动到靠近这些音符的画布空白区域，按住左键不放，然后拖动鼠标“画”出一个矩形区域。所有在区域内的音符都会被选中。松开鼠标按钮即可完成选择。

{{< figure src="en/rubberband-selection.png" alt="Rubberband selection" >}}

最后，如果你需要选择所有音符，只需按 **Ctrl+A**。

一旦你选择了多个音符，你可以通过多种方式对它们进行批量编辑。

## 编辑音符的开始和结束

要编辑音符的开始或结束位置，请将鼠标悬停在音符的边缘，直到看到鼠标指针改变图标。然后按住鼠标左键，向左或向右拖动进行编辑，松开鼠标按钮以确认编辑。

当启用吸附时，吸附选项会在此处生效。此外，如果选择了多个音符，它们都将被缩短或延长。

{{< figure src="en/drag-note-ends.png" alt="Drag note ends" >}}

量化实际上是指调整音符的开始和结束时间，使它们吸附到你选择的网格上。这是你在实时录音后可能会用到的功能。Ardour 在应用量化时提供了一定的灵活性：你可以只吸附开始、只吸附结束，或者两者都吸附。

另一个有效调整音符时值的命令是 _连奏化_。当你有两个在时间线上不同位置开始的音符时，_连奏化_ 会调整较早开始的音符的结束位置，使其准确地在第二个音符开始的地方结束。这可能意味着延长或缩短较早那个音符的时值：

{{< figure src="en/legatize.png" alt="legatize" >}}

正如你所看到的，第一个音符被延长以连接第二个，第二个被缩短以连接第三个，第三个被延长以连接第四个。

## 移动和移调音符

你可以通过按键盘上的方向键来移动和/或移调选中的音符。或者，你可以将鼠标悬停在所选节点之一的中部，按住鼠标左键，然后向左/右或上/下拖动（或同时拖动）。

你也可以一次性移调指定数量的八度和半音。右键点击选中有音符的片段，选择 _移调..._。然后指定要移调的八度和半音数量。

{{< figure src="en/transpose.png" alt="Transpose MIDI notes" >}}

## 编辑力度

Ardour 使用两种方式来表示音符的力度：颜色编码和 2D 图表。

{{< figure src="en/velocities.png" alt="Velocities" >}}

音符颜色越浅，音符内部的深色线越短，力度就越低。深红色的音符和贯穿整个音符的深色线意味着力度处于（或接近）其最大值。

要快速更改音符的力度，请将鼠标悬停在画布上的音符中部，然后开始上下滚动鼠标滚轮来更改力度值。当选择了多个音符时，每个音符都将收到相同的调整量。所以，你可以选择比如力度值分别为 25、50 和 100 的 3 个音符，将每个增加 20，最终得到的音符力度分别为 45、70 和 120。

{{< figure src="en/velocity-tooltip.png" alt="Velocity tooltip" >}}

以数值方式更改力度（以及 MIDI 通道、音高和位置）的一种简单方法是使用音符的属性对话框。右键点击一个或多个音符，然后选择 _编辑…_。

![Editing note properties](en/note-properties.png?width=45vw)

如果选择了多个音符，你可以批量将它们更改为相同的值。为此，在应用更改之前，启用 _将选中音符设为此力度_ 选项。

## 从头到尾的编辑示例

让我们看看这个快速的实时演奏录音。

{{< figure src="en/example-original.png" alt="" >}}

即使不听，也有几点很突出：

- 开始时间错误；
- 时值错误；
- 力度参差不齐。

让我们修复它，从位置和时值开始。

1. 按 **E** 切换到 _内部编辑_ 模式。橡皮筋选择所有可见音符。

{{< figure src="en/example-select-all.png" alt="" >}}

2. 右键点击并选择 _量化_（或直接按 **Q**）。使用 _1/8 音符_ 或 _主网格_ 来设置音符的开始和结束，因为在这种情况下，它们是一回事。

{{< figure src="en/example-quantize-dialog.png" alt="" >}}

这已经好多了：

{{< figure src="en/example-quantize-result.png" alt="" >}}

但有一些重叠的音符。

3. 右键点击并选择 _连奏化_。

{{< figure src="en/example-legatize.png" alt="" >}}

4. 按一次 **向左箭头** 键，将所有选中的音符移动一个网格单位（即 _1/8 音符_），使它们正好从小节的开头开始：

{{< figure src="en/example-shift-left.png" alt="" >}}

位置现在都没问题了。但还有更多细节需要处理

5. 是时候清理力度了。选中两个小节中除第一个音符之外的所有音符。你可以通过按 **Ctrl+A** 来做到这一点，然后按住 **Ctrl** 并点击每个小节中的第一个音符以取消选中它们。或者，你可以橡皮筋选择第一部分（没有第一个音符），然后按住 **Shift** 添加第二部分（也没有该小节中的第一个音符）。

{{< figure src="en/example-select-all-but-firsts.png" alt="" >}}

6. 右键点击，选择 _变换_。我们需要将其设置为大致相同的较低力度，比如 60。所以我们设置力度，将其设置为一个精确值，并使用 60：

{{< figure src="en/example-transform-all-60.png" alt="" >}}

这再次好多了：

{{< figure src="en/example-now-all-60.png" alt="" >}}

但如果我们保持这样，听起来会有点太机械了。

7. 让我们再次调出 _变换_ 对话框，并添加一点点随机变化：

{{< figure src="en/example-transform-variation-56-to-64.png" alt="" >}}

鉴于变化范围很小，差异不会很明显。但如果你将鼠标悬停在单个音符上，你会看到音符的力度现在大约在 56 到 64 之间。

8. 最后，点击第一小节的第一个音符，使用鼠标滚轮滚动将其力度设置为 82，然后对第二小节的第一个音符重复此操作。你现在将拥有一个规律的力度模式，每个小节的第一个音符听起来都比该小节其余的音符更响亮。

{{< figure src="en/example-regular-velocity-pattern.png" alt="" >}}
