在本节中，你将学习更多可以对片段执行的操作。

右键点击选中的片段会显示一个上下文菜单。菜单中的第一项（以片段名称标记）包含一个大型子菜单。所有这些操作也都可以在 Ardour 的主 *区域* 菜单中找到。

本节介绍这些菜单中一些最常用的操作。

{{< figure alt="Region menu" src="en/ardour7-region-menu.png" >}}

**播放**
: 从该片段开头播放到结尾（**H** 快捷键）。

**标签**
: 为片段添加一些有意义的标签，例如“Good”，以便在 _片段_ 列表中与其他片段区分开。

**循环**
: 将循环范围设置为适应该片段的时值，并立即开始循环播放。

**重命名**
: 更改片段的名称。

**属性**
: 包含大量关于该片段的信息，并且可以更改其增益。

**位置**
: 在这个子菜单中，除了其他选项外，你还会找到 _锁定_ 切换框：它会锁定片段，使其无法被移动或修剪。不过，它仍然可以被分割，而分割后产生的片段将解除锁定。

**编辑**
: 此子菜单包含一些有用的工具，例如 _音高变换_（**Alt+8**）和 _反转_（**Alt+4**）。_音高变换_ 会在不改变片段时值的情况下改变其音高。_反转_ 会使片段反向播放。

**增益**
: 包含一些有用的选项，例如 _静音_（**Alt+1**）、_标准化_（**Alt+3**）、_提升增益_（**Alt+6**）和 _降低增益_（**Alt+7**）。

**复制**
: 包括 _复制_（快捷键 **Alt+D**）、_多重复制_ 和 _填充轨道_。这些内容已在 [处理片段](../working-with-regions) 章节中详细解释。

**响度分析**
: 以 LUFS 为单位估算片段的响度，以及 _峰值_ 和 _真峰值_ 值。

**频谱分析**
: 显示该片段整体频率内容的窗口。

请随意自行探索上面未提及的其他子菜单。其中许多都是 Ardour *区域* 菜单下选项的镜像。下面我们会更详细地介绍一些最有用的功能。

## 音高变换

_音高变换_（**Alt+8**）功能会在不改变片段时值的情况下改变其音高。该功能会应用一种音高变换算法，基于源片段创建一个新的音频剪辑。

_音高变换_ 窗口允许用户指定所需的移调量和方向。该窗口包含一个 _保留共振峰_ 选项。当进行大幅度音高变换时，保留共振峰选项可以让结果听起来稍微更自然，尤其是在处理人声素材时。

![Pitch Shift](en/ardour7-pitch-shift-window.png?height=30vh)

## 标准化

_标准化_ 功能（**Alt+3** 快捷键）会以非破坏性的方式提升所选片段的电平，使其 _峰值_ 处于 0 dB 或更低。当标准化到 0.0 时，片段将在避免削波的同时尽可能响亮。有时你可能会发现将片段标准化到小于 0 的值很有用，例如 -1.0、-3.0 或 -6.0 分贝，这样它就不会变得太响。

![Normalize](en/ardour7-normalize-window.png?width=20vw)

另外两个有用的片段增益操作是 _提升增益_（**Alt+6**）和 _降低增益_（**Alt+7**），它们均以 1dB 为单位向上或向下调整增益。请务必尝试一下。

## 反转

_反转_（**Alt+4**）功能会反转选中的音频片段，实际上就是让它反向播放。反转片段会在“后台”创建一个新的音频文件。

## 对两个或多个选中范围的操作

如果选中了多个范围，该操作将应用于所有范围（例如 _标准化_、_反转_ 等）。

### 组合

上下文菜单中的一些操作只有在选中两个或多个片段时才会变为可用。例如，让我们看看 _编辑_ 子菜单下的 _组合_ 功能。首先我们选择两个相邻的片段：

{{< figure alt="combine" src="en/ardour7-region-combine-1.png" >}}

然后我们从右键上下文菜单中选择 _组合_，或者从 Ardour 的主菜单 `区域 > 编辑 > 组合` 中选择：

{{< figure alt="combine 2" src="en/ardour7-region-combine-2.png" >}}

结果，选中的片段被组合成了一个。当你找到了一组完全符合你要求的片段序列，并且希望将整个序列作为一组进行复制和/或移动时，这特别有用。

请注意，组合后的片段名称中会带有“compound”一词。

{{< figure alt="combine 3" src="en/ardour7-region-combine-3.png" >}}
