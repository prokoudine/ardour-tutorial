我们已经初步了解了 _抓取_ 模式（选择/移动对象）和 _范围_ 模式。在本章中，我们将概述 _编辑器_ 窗口该区域中可用的所有 _编辑模式_ 和 _光标模式_。

![Ardour Edit Modes](zh/ardour9-edit-modes.png?width=30vw)

## 编辑模式

这些控件定义了主画布的行为以及光标的不同功能。

_编辑_ 模式下拉菜单包含三个选项：

**滑行模式**
: 这是标准模式。它允许你在水平方向（同一轨道内）和垂直方向（轨道之间）自由拖动片段。

**波纹模式**
: 当你剪切或移动其中一个片段时，自动移动其他片段。例如，如果你剪掉一段音频采访中不感兴趣的部分，Ardour 会将所有轨道中的所有片段向左移动，这样原来有内容的地方就不会出现静音。

**锁定模式**
: 无论开启此模式后你如何编辑片段，片段的内容都会始终停留在原位。你只能在轨道之间上下移动片段，而不能左右移动。

在本教程中，我们只会使用 _滑行_ 编辑模式。

## 编辑点

编辑点定义了各种编辑操作发生的位置。以剪切/分割为例……

**指针**
: 片段将在指针位置被分割。

**标记**
: 片段将在所选片段范围内的最后一个标记处被分割。

**鼠标**
: 所选片段将准确地在鼠标指针下方被分割。

## 光标模式

### 抓取模式

![G](zh/ardour9-grab-edit-mode.png?width=20vw)

此光标模式（**G** 快捷键）允许你选择或移动对象，例如片段和（自动化曲线中的）断点。选择此光标模式后，你的光标指针会变成一个小手图标。

### 范围模式

![R](zh/ardour9-range-edit-mode.png?width=20vw)

此光标模式（**R** 快捷键）允许你单击并拖动来定义或调整时间范围。选择此光标模式后，你的光标指针会变成一条竖线。根据你选择的轨道，可以在一个或多个轨道上选择时间范围。

## 智能模式

![3](zh/ardour9-smart-mode.png?width=20vw)

启用此模式后，根据鼠标指针在片段上方的准确位置，Ardour 将提供抓取功能（例如抓取并移动片段）或范围功能（选择范围）。

### 切割模式

![C](zh/ardour9-cut-edit-mode.png?width=20vw)

使用此光标模式（**C** 快捷键）将片段分割成更小的片段。光标会变成剪刀形状。这允许你指向并单击片段，在光标处将其分割。

{{< callout type="info" >}}
你也可以直接从 _抓取_ 模式剪切片段（有时这种方法更实用）。无需离开 _抓取_ 模式，只需将鼠标放在要剪切的片段上的所需位置，然后按 **S** 快捷键（代表“split”）。重要提示：你的编辑点（位于 _模式_ 工具栏左侧）必须设置为 _鼠标_。
{{< /callout >}}

### 拉伸/收缩片段

![T](zh/ardour9-stretch-shrink-edit-mode.png?width=20vw)

此光标模式（**T** 快捷键）允许你拖动并调整整个片段的持续时间，而不改变音高。这有时被称为“时间拉伸（time stretching）”，因此有了 **T** 快捷键。详情请参阅 _拉伸/收缩片段_ 章节。选择此光标模式后，你的光标指针会变成一个斜箭头。

### 网格模式

{{< figure alt="D" src="en/ardour8-grid-mode.png" >}}

此模式（**Y** 快捷键）允许编辑速度映射，以适应作为音频轨道录制的现场演奏的速度波动。这会将音频轨道作为参考，基于此速度映射构建的 MIDI 片段将与原始音频完美同步。

在小节线上方单击会插入一个新的速度标记，紧接着左右拖动会增加/降低速度值。

在小节线之间左右单击并拖动会创建一个速度渐变——两个速度标记之间的速度逐渐变化。

### 绘制模式

{{< figure alt="D" src="en/ardour8-draw-edit-mode.png" >}}

此模式（**D** 快捷键）有 4 个使用场景：

1. 绘制新的自动化点（自动化将在[使用自动化](../../mixing-sessions/using-automation/)章节中详细讨论）。
2. 绘制新的 MIDI 片段。
3. 在 MIDI 片段中绘制新的 MIDI 音符。
4. 当片段被充分放大时，编辑现有的 MIDI 音符和自动化点。

如果你没有放大得足够大，很容易创建出你并不需要的新的 MIDI 音符或新的自动化点。如果这成为问题，你应该使用下一个模式，该模式只允许编辑现有的点和音符，而不允许创建新的。

对于绘制 MIDI 音符，工具栏还额外提供了默认音符长度、MIDI 通道和力度的控件。

### 内部编辑模式

![E](zh/ardour9-internal-edit-mode.png?width=20vw)

使用此模式（**E** 快捷键）编辑现有的自动化点或 MIDI 音符。

对于自动化点，光标看起来像一只手，当你在现有节点上方时，它会变成一个小十字。单击、按住并拖动即可移动节点。

对于 MIDI 音符，当你的光标悬停在音符中间时，光标看起来像一只手，上方有一个四分音符，这是为了选择并移动音符。将鼠标悬停在音符的左边界或右边界会改变光标，并允许调整音符的开始/结束位置（以及持续时间）。

对于自动化点和 MIDI 音符，你都可以按住 **Ctrl** 键并单击多个项目，将它们添加到所选项目中，然后一起移动多个音符或节点。

{{< figure src="en/ardour7-internal-edit-mode-multiple-points.png" alt="Moving multiple automation points" >}}

具体对于 MIDI 音符，你还可以使用橡皮筋选择：将光标放在现有音符之外的任何位置（光标将失去四分音符符号），然后按住鼠标左键并开始拖动。会出现一个选择框。它接触到的所有音符都会被选中。

{{< figure src="en/ardour7-internal-edit-mode-rubberband-selection.png" alt="Rubberband selection of notes" >}}
